Integrante
Rafael B. Vieira

Descrição do Projeto
Este projeto utiliza o conjunto de dados Appliance Energy Prediction, disponível no Kaggle, para análise de medições de sensores relacionados ao consumo energético residencial.

Caracterização do Dataset
Domínio de Engenharia
O conjunto de dados pertence à área de eficiência energética e automação predial, envolvendo medições de temperatura, umidade e consumo de energia elétrica em ambientes residenciais.

Dimensões
19.735 registros (linhas)
29 variáveis (colunas)
Formato
Arquivo CSV
Estrutura tabular
Cabeçalhos na primeira linha
